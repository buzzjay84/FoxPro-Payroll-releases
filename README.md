# Fox Pro Payroll

Releases of **Fox Pro Payroll**: a modern Windows interface for the original FoxPro payroll system used by DepEd personnel offices. It works on the same payroll files as the original, so changes made in either one show in the other.

Download the latest installer from [Releases](../../releases/latest): `FoxPro-Payroll-Setup-<version>.exe`

- Works on Windows 7 SP1 through Windows 11. Windows 7 needs .NET Framework 4.8 installed first.
- No administrator rights needed. The first time it opens, choose your FoxPro payroll folder.

The source code is private. This repository only builds and publishes the installers.
